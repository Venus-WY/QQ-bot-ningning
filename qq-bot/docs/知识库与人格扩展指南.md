# 知识库与人格扩展指南

本 bot 的"知识库"就是它的**人格蒸馏产物**——位于 `corpus/` 下的一组只读数据文件，
运行时由 `qq-bot/src/plugins/qqbot/distilled_persona.py` 加载并拼进 system prompt。

本文说明：① 这套知识库的结构与接口；② 如何给现有角色加背景知识；③ 如何蒸馏一个全新角色。

---

## 1. 知识库结构总览

```
corpus/
├── persona/                    # 人格蒸馏产物（只读，运行时加载）
│   ├── personality.yaml        # 核心人格特质
│   ├── speech.yaml             # 语言习惯 + 客观语言画像
│   ├── behavior.yaml           # 情境反应
│   ├── social.yaml             # 关系档位语气
│   └── qq_adaptation.yaml      # QQ 群适配层（背景记忆/人物关系/安全护栏/插话倾向）
├── fewshot.jsonl               # few-shot 范例库（运行时按 bigram 检索注入）
└── hanxiao_lines.jsonl         # 提取的原始语料（中间产物，已 gitignore，仅用于重新蒸馏）
```

人格来源由 `qq-bot/config.yaml` 的 `persona.source` 控制：
- `hanxiao`：加载上述蒸馏人格（`distilled_persona.py`）
- 其它值（如 `luna`）：回退到 `config.yaml` 里 `persona.*` 的简单数值人设（`persona.py`）

## 2. 数据接口（字段格式）

### 2.1 personality.yaml —— 核心人格

```yaml
module: personality
traits:
  - name: 冷静理性的实用主义者     # 特质名
    description: 面对危机优先权衡利弊……  # 一句话说明
    evidence: ["0498:第238章"]      # 证据 ID（来源语料，可追溯，不参与运行时）
    example: 不能再拖下去……          # 一条原话例证
```

### 2.2 speech.yaml —— 语言习惯

```yaml
module: speech
stats:                              # 客观语言画像（本地统计，非 LLM 生成）
  count: 2790
  median_chars: 13.0
  question_rate: 0.229
  exclamation_rate: 0.038
  particle_per_char: 0.0114
patterns:                           # LLM 提炼的语言规则
  - category: 毒舌吐槽              # 维度名
    pattern: 用轻描淡写的语气说出刻薄话……
    example: 说得好，关我什么事？
    evidence: ["0616:第281章"]
```

### 2.3 behavior.yaml —— 情境反应

```yaml
module: behavior
situations:
  被质疑/挑衅:
    reaction: 冷静反击，用事实或行动让对方闭嘴。
    evidence: ["0015:第003章"]
    example: ''
```

### 2.4 social.yaml —— 关系档位语气

```yaml
module: social
stages:
  stranger: {tone: 轻蔑、威胁、冷酷……, evidence: ["0616:第281章"]}
  acquaintance: {tone: 客气、疏离……, evidence: [...]}
  friend: {tone: 随意、轻松、调侃……, evidence: [...]}
  close_friend: {tone: 亲密、关心……, evidence: [...]}
```

### 2.5 qq_adaptation.yaml —— QQ 群适配层（扩展点最多）

| 字段 | 类型 | 作用 |
| --- | --- | --- |
| `default_relationship` | str | 群友默认关系档位 |
| `no_auto_romance` | bool | 不主动进入恋爱关系 |
| `lore_mention` | str | `minimal` = 少提原作设定 |
| `lore_background` | str | 角色背景记忆（被问起时回答） |
| `character_relations` | map | **人物关系表**（见下） |
| `romance_downgrade` | str | 恋爱话题降格规则 |
| `behavior_guard` | str | 极端台词安全护栏 |
| `should_speak` | map | 插话倾向（喂给插话判断） |

**人物关系表 `character_relations`**（群聊提到这些名字时触发特殊反应）：

```yaml
character_relations:
  海拉:
    relation: 你的副军团长兼老朋友……   # 你与 TA 的关系
    reaction: 语气会柔和几分、护着她……  # 群聊提到 TA 时你的反应
  异神:
    relation: 你的宿敌，宇宙级的对头
    reaction: 会警惕、嘲讽，语气带敌意
```

运行时逻辑：`distilled_persona.build_relation_hint(context_text)` 扫描最近群聊，
若命中 `character_relations` 里的人名，就把对应关系记忆追加进 system prompt，
从而触发"特殊反应"。**人名出现即触发，无需改代码。**

### 2.6 fewshot.jsonl —— 范例库

```json
{"tags": ["conflict"], "emotion_state": "neutral", "relationship_stage": "friend",
 "context": "吕倩脸色古怪，指着门口……", "response": "他是不是在追你？",
 "behavior_summary": "吕倩指门口人，韩萧反问追求"}
```

## 3. 方式一：给现有角色加背景知识（最快，纯配置）

不用改代码，直接编辑 `corpus/persona/qq_adaptation.yaml`：

1. **加背景记忆**：扩充 `lore_background`，写清角色的来历、身份、能力。
2. **加人物关系**：在 `character_relations` 下新增条目，格式如上。别人在群里提到该名字，角色就会带对应情绪反应。
3. **调插话倾向**：改 `should_speak` 的档位（`必回/高/中/低`）。

改完重启 bot 即可生效（`distilled_persona._load_all` 有 `lru_cache`，进程内首次加载后缓存，需重启进程或热重载触发）。

## 4. 方式二：蒸馏一个全新角色（完整流程）

现有脚本以"韩萧"为例，换角色时照搬改名字即可。四步：

### 步骤 1：准备语料

把目标角色的文本（小说/剧本/对话集）放到仓库根目录，编码需 `gb18030` 或 `utf-8`。
若是其他编码，先转码：`iconv -f GBK -t UTF-8 原文.txt > corpus.txt`。

### 步骤 2：提取角色台词

复制 `qq-bot/scripts/extract_hanxiao.py` 为新脚本，改两处：
- `NAME = "目标角色名"`（脚本顶部）
- 正则里对应该角色的说话方式（前置式 `XX道："..."` / 后置式 `"..."XX吐槽`）

运行后得到 `corpus/<角色>_lines.jsonl`，字段：
`{text, type(spoken/inner), verb, ctx_before, ctx_after, chapter}`。

### 步骤 3：蒸馏人格（LLM）

复制 `distill_hanxiao.py`，把 system prompt 里的"韩萧/超神机械师"改成目标角色，
再按模块运行：

```bash
python scripts/distill_新角色.py --module personality
python scripts/distill_新角色.py --module speech
python scripts/distill_新角色.py --module behavior
python scripts/distill_新角色.py --module social
```

产物覆盖 `corpus/persona/*.yaml`（四个模块各自对应一个文件）。

### 步骤 4：生成 few-shot + 适配层

```bash
python scripts/build_fewshot_新角色.py --target 400   # 生成 corpus/fewshot.jsonl
```

再手写 `corpus/persona/qq_adaptation.yaml`（背景、人物关系、护栏、插话倾向）。

最后改 `qq-bot/config.yaml` 的 `persona.identity`（名字/角色/风格）与 `persona.source`。

## 5. 代码接口（扩展点）

运行时加载器 `qq-bot/src/plugins/qqbot/distilled_persona.py` 暴露以下函数：

| 函数 | 作用 |
| --- | --- |
| `build_system_prompt(cfg)` | 组装完整 system prompt（人格 + 背景 + 护栏） |
| `build_fewshot_block(context_text, k)` | 按 bigram 重叠检索 k 条 few-shot 拼成示例块 |
| `build_relation_hint(context_text)` | 扫描群聊命中人物关系，返回关系记忆 |
| `should_speak_hint()` | 插话判断用的倾向提示 |

主流程在 `qq-bot/src/plugins/qqbot/__init__.py` 的 `_reply()`：

```python
system_content = distilled_persona.build_system_prompt(config)   # 基础人格
system_content += memory.get_speaker_block(...)                   # 长期记忆（按人）
system_content += distilled_persona.build_fewshot_block(ctx)      # few-shot 范例
system_content += distilled_persona.build_relation_hint(ctx)      # 人物关系触发
```

### 5.1 如何加"外部知识检索"（RAG 风格）

若想接入任意外部知识（文档、维基、笔记），在 `_reply()` 里 `build_relation_hint` 之后
再追加一段自定义检索结果即可，模式完全一致：

```python
# 伪代码：检索外部知识库，把最相关片段注入 system prompt
hits = your_knowledge_base.search(context_text, top_k=3)
for h in hits:
    system_content += f"\n\n【相关知识】{h}"
```

只要 `system_content` 是发给大模型的 system 消息，任何"知识"都能以这种方式注入，
不需要改动 nonebot 适配层。

## 6. 常见问题

- **改了 yaml 不生效**：`_load_all` 有 `lru_cache`，需要重启 bot 进程（或触发热重载）。
- **evidence 里 ID 失效**：重新提取语料后行号会变，evidence 仅用于可追溯，不影响运行时。
- **few-shot 检索不到**：检索靠 `context + response + behavior_summary` 的二元组重叠，context 为空时仍能靠后两者命中。
