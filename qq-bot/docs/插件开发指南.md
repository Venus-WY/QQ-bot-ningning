# 插件开发指南（给朋友看的）

这个项目基于 **NoneBot2**，加装新功能 = 在 `src/plugins/` 下新建一个文件夹，其余都自动生效，**不用改任何核心代码**。

---

## 一、最快上手：复制 `fortune` 改一改

参考现成的示例插件 `src/plugins/fortune/`（今日运势），它演示了全部要点。

**最小模板**（一个能响应 `/你好` 并回复的插件）：

```python
# src/plugins/my_plugin/__init__.py
from nonebot import on_command
from nonebot.adapters.onebot.v11 import Bot, GroupMessageEvent

greet = on_command("你好", priority=5, block=True)

@greet.handle()
async def _(bot: Bot, event: GroupMessageEvent):
    await bot.send_group_msg(group_id=event.group_id, message="你好呀！")
```

把 `my_plugin` 文件夹放进 `src/plugins/` 后重启 bot 即可，群里发 `/你好` 就会回。

---

## 二、触发方式（三选一或组合）

| 需求 | 写法 | 触发示例 |
| --- | --- | --- |
| 命令 | `on_command("运势")` | `/运势` |
| 关键词 | `on_keyword("今日运势")` | 消息里含「今日运势」 |
| 任意消息 | `on_message()` | 每条群消息都进（慎用） |

- `priority`：数字越小越先处理，核心 AI 群友是 10，示例插件用 5。
- `block=True`：命中后不再往下传（防止和别的插件重复响应）。

## 三、发送消息

```python
await bot.send_group_msg(group_id=event.group_id, message="要发的内容")
```

- 群里直接发用 `send_group_msg`；想回复某人可用 `message=Message(f"[CQ:reply,id={event.message_id}]") + 内容`。
- 发完后用 `await matcher.finish("...")` 可以「发出并立即结束」，避免一个触发走多条回复。

## 五、调用 DeepSeek（复用共享客户端，别自己 new）

```python
from src.plugins._shared import chat, chat_json

# 生成一段文本
reply = await chat([
    {"role": "system", "content": "你是群里的宁宁，简短可爱。"},
    {"role": "user", "content": "今天天气不错，说一句。"},
], max_tokens=80)

# 要模型输出结构化 JSON（如抽签、判断）：
data = await chat_json([
    {"role": "system", "content": "输出 JSON：{\"tag\": \"...\"}"},
    {"role": "user", "content": "..."},
])
```

> 为什么用 `_shared` 而不是自己 `from openai import ...`：共享客户端已经处理好了 API key、模型名、以及一个 Windows 系统代理的坑（`trust_env=False`），自己写容易踩雷。

## 六、读配置

```python
from src.plugins._shared import config

print(config.groups)      # 群白名单列表
print(config.name)        # 机器人名字（现在是「宁宁」）
print(config.llm_model)   # 模型名
```

要加**你自己插件专属的配置**，可以在 `config.yaml` 顶层加一节，然后：

```python
import yaml
from pathlib import Path
raw = yaml.safe_load(open(Path(__file__).resolve().parents[3] / "config.yaml", encoding="utf-8"))
my_cfg = raw.get("my_plugin", {})
```

## 七、重要注意事项（坑）

1. **不要在模块顶层 import 别的插件包**（比如 `from src.plugins.qqbot import ...`）。这会触发 NoneBot2 的 `"not loaded as a plugin"` 报错。共享代码一律走 `_shared`。
2. 插件文件夹**不要以 `_` 开头**——`_` 开头会被 NoneBot2 当作「非插件」跳过（`_shared` 正是靠这个约定不被加载）。
3. 一个插件文件夹只放一个功能；命名用英文/拼音（如 `weather`、`fortune`），避免中文路径出问题。
4. 需要调用外部 API（如天气）时，把 key 写进 `.env`，用 `os.getenv("XXX")` 读，别硬编码在代码里。

## 八、想复用「宁宁完整人格」回复（进阶）

`_shared.chat` 是「裸」客户端，不带人格。如果你想让插件回复也带上完整的宁宁人设，可以用 NoneBot2 的依赖注入 `nonebot.require("src.plugins.qqbot")` 拿到核心插件导出的能力——这属于进阶玩法，需要核心插件主动 `export()` 暴露接口，目前核心尚未暴露，先不要直接 import。有需要再找维护者加。
